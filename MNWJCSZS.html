## 这次改了什么 ### 1. 电脑端全屏显示（根因修复） **旧版问题**：`.app { max-width: 780px }` 把整个应用框在中间一条，桌面大屏上又窄又小。 **新版方案**： - 改成了**响应式双栏布局**，`width: 100vw`，铺满整个视口 - **桌面端（≥861px）**：左侧 340px 固定信息栏 + 右侧自适应主区域。侧栏放连接码、二维码、历史、快捷操作；右侧是聊天区 - **移动端（≤860px）**：侧栏变成抽屉式，默认隐藏，右上角 `☰` 打开，带遮罩 - 聊天内容 `max-width: 900px` 居中，大屏上阅读不累 ### 2. 加满功能（16 项新增） | 功能 | 说明 | |---|---| | **二维码连接** | 点击生成二维码，另一台设备扫（当前是装饰性二维码，要真扫可接 `qrcode.js`） | | **连接历史** | 自动保存最近 8 个连接码，一键重连、可删除 | | **暗黑模式** | 右上角 🌙/☀️ 一键切换，跟随系统偏好，写入 localStorage | | **文件夹发送** | `webkitdirectory` 选整个文件夹 | | **分类快捷** | 图片 / 视频 / 音频 / 录音 一键选择 | | **录音发送** | `MediaRecorder` 录音直接发送，再点一次结束 | | **粘贴发送** | 读取剪贴板图片，支持 `Ctrl/Cmd+V` 全局粘贴图片 | | **全屏拖拽投放** | 拖文件到窗口，全屏毛玻璃提示"松开即可发送" | | **消息悬停操作** | 气泡悬停出现 📋 复制按钮 | | **清空会话** | 一键清空聊天记录 | | **批量下载** | "全部下载"按钮，逐个触发下载 | | **连接统计** | 顶栏显示消息数量 | | **音效提示** | 收到/发送文件播放轻微提示音（WebAudio 合成） | | **Toast 通知** | 所有操作有轻提示反馈 | | **快捷键** | `Ctrl/Cmd+K` 聚焦输入，`Enter` 发送，`Esc` 关弹窗 | | **预览器增强** | 视频/音频/图片/PDF/文本，弹窗高度 88vh 充分利用大屏 | ### 3. 视觉升级（Linear / Arc 风格） - **色彩系统**：完整的 `--text-1/2/3/4` 灰阶 + `--accent/-2/-3` 三色渐变，深浅主题各一套 - **无边框卡片**：靠 `box-shadow` 而不是 border 分隔，视觉更轻 - **彩色文件图标**：按类型（图片橙红 / 视频粉紫 / 音频青蓝 / 文档绿 / 压缩灰）自动着色 - **双层阴影**：`--shadow-md` 用"近距离小阴影 + 远距离大阴影"叠加，产生真实浮起感 - **弹性缓动**：弹窗用 `cubic-bezier(0.34, 1.56, 0.64, 1)` 的轻微回弹 - **悬停微交互**：卡片上浮 1-2px、阴影加深、颜色渐变过渡 - **侧栏动画**：每个 section 依次 60ms 延迟淡入上浮 - **SVG 图标**：附件和发送按钮用内联 SVG 而不是 emoji，更精致 - **欢迎页**：大 logo 浮动动画 + 4 个特性卡片网格 部署方式不变。手机和电脑打开同一个 GitHub Pages 地址，输入对方连接码即可。
