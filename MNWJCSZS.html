## 这版改了什么 ### 1. 布局重做（解决"第一次用不知道干嘛"） - **删掉侧栏**，改单栏居中布局（最大 900px） - **连接页放主区域**，一打开就能看到： - ① 我的连接码（大号显示 + 复制 + 二维码按钮） - ② 扫码连接（大按钮，一眼就知道能扫） - ③ 或输入连接码（输入框 + 连接按钮） - ④ 最近连接（有历史才显示） - **连接成功后自动切聊天**，连接页和底栏自动隐藏 - 顶栏随状态切换：未连接时显示 📱 二维码按钮，连接后换成 ⋯ 菜单 ### 2. 二维码内嵌生成器（彻底解决生成不出来） - 把 `qrcode-generator` 的核心代码**内嵌进 HTML**（约 500 行），不依赖任何 CDN - 支持自动版本选择（1-40） - 用 canvas 渲染，清晰、兼容性最好 - 如果还失败会明确报错，不会静默 ### 3. 精简功能（删掉没用的） **删掉**： - 侧栏、欢迎页的装饰 - "选图片/视频/音频"三个按钮（📎 已能选全部） - "选择文件夹"（合并进 📎 的 accept） - 音效提示 - 装饰性动画 **保留并整合**： - 底栏 📎（选文件）+ 🎙（录音，带红色脉冲状态） - 顶栏 ⋯ 菜单：粘贴发送 / 全部下载 / 清空记录 / 断开连接 ### 4. 保留真有用的 - 扫码（html5-qrcode） - 二维码（内嵌生成器） - 断线自动重连（3 秒一次，最多 10 次） - 传输速度 + 剩余时间 - 暂停/继续/取消发送 - 预览器（图片/视频/音频/PDF/文本） - 主题切换 - 连接历史 ## 部署 上传到 GitHub Pages，手机和电脑打开同一个地址。手机扫码 → 自动连电脑，或电脑扫手机码。首次打开扫码会请求摄像头权限，允许即可。
